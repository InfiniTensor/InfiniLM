FlashInfer v0.6.7 (56ed54098411946525da17eca2bcfd7ec72a515e) generates sampling
from csrc/{sampling.cu,renorm.cu,flashinfer_sampling_binding.cu}; their source
include closure does not contain FA3, CUTLASS, fmt or spdlog. TVM-FFI v0.1.10
(1fed0ae0421e614d45662e8ee6bcae353d3ab2ea) builds libtvm_ffi from the native
object lists in CMakeLists.txt, including DLPack interfaces and optional
libbacktrace. Its PyTorch-derived optional Python DLPack addon is not in those
object lists. These source-based distinctions, not Python import behavior,
scope the checked-in fallback materials to the two native artifacts.
They do not cover arbitrary replacement binaries or the complete Python wheels.
The resolver additionally collects existing license/NOTICE/COPYING materials
from actual package metadata. That conservative package inventory can include
materials for components outside these two DSOs; it is intentionally not filtered
by fixed hashes or used to restrict build capability. A complete wheel or SDK
redistribution must retain its own applicable notices, including secondary ones.
